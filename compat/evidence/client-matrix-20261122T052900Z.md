## Limits

The headless llvmpipe stack cannot prove shader fidelity, leaf/entity culling correctness or
Dynamic FPS throttling. Those PARTIAL rows need a hardware-GPU client for visual verification.
Complementary/Sildur need a GPU to finish pipeline creation; the Oculus/Embeddium/BSL path is
functional without one.
